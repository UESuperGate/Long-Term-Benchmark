usage: run_agent_eval.py [-h] (--static-check | --preflight | --execute)
                         [--platform {android,arkts}] [--timeout TIMEOUT]
                         [--run-id RUN_ID] [--candidate-root CANDIDATE_ROOT]
                         [--output OUTPUT]

WordPress 05 isolated OpenCode + MiniMax-M3 agent runner

options:
  -h, --help            show this help message and exit
  --static-check        Validate paths, toolchains, public-input redaction,
                        and policy without builds
  --preflight           Build visible and hidden controls offline; never
                        invoke OpenCode or a device
  --execute             Start the authorized formal agent run, including
                        runtime device scoring
  --platform {android,arkts}
                        Platform to check or run; repeat for both (default:
                        both)
  --timeout TIMEOUT     Overall deadline per top-level platform run; must be
                        3600
  --run-id RUN_ID       Formal run identifier; required with --execute
  --candidate-root CANDIDATE_ROOT
                        Formal clean-room candidate root
  --output OUTPUT       Static/preflight report path
