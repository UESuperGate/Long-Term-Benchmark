# Native semantic boundary

`execution.json` invokes the shared API 23 HDC runner in `migrations/tools`.
`EntryAbility` loads the production ArkUI `Index` page. The injected observer is
called from `Index.aboutToAppear` with that page's existing
`MediaKeyboardPageOwner`; it may configure only the owner's external leaves and
must establish derived givens through owner actions. Runtime rows carry one
owner ID for all cases and are rejected if the page lifecycle or owner binding
is absent. If no API 23 target or native observer is available, every case
remains `not_scored`.
