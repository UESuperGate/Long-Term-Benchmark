# Native semantic boundary

`execution.json` invokes the shared API 23 HDC runner in `migrations/tools`.
`EntryAbility` loads the production ArkUI `Index` page. The injected observer is
called from `Index.aboutToAppear` with that page's existing
`StickerManagementPageOwner`; it configures external repository leaves and
builds derived givens through owner actions. The persisted-order case recreates
the owner's store/repository graph and reloads from the same leaf before its
after snapshot. Missing page ownership, lifecycle, or reopen evidence is never
scored. If no API 23 target is available, every case remains `not_scored`.
