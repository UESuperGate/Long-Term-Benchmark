# Android runtime test design

The API 37 instrumentation establishes Room-like membership inputs through evaluator-owned leaves and invokes candidate-owned Saved entry actions. It records given/before/event/after, external effects, persistent-store reopen evidence, and independent invariant checks for all ten canonical cases. Missing bindings and crashes are `not_scored`; the scorer never falls back to source observation.

The retained upstream Reading Lists files are byte-exact provenance snapshots, including the areas without upstream JUnit coverage. The focused installable project currently executes a candidate-owned action adapter; direct whole-file execution of the retained Fragment/ViewModel classes remains a recorded publication gate.
