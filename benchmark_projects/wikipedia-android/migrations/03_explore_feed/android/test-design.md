# Android runtime test design

The API 37 instrumentation owns fixtures and assertions. Candidate production owns `ExploreActionPrefix` and never receives a testcase ID. Each episode records canonical given/event data, pre-event state, post-event state, invoked production entry methods, effects, preference-store reopen evidence, and independent invariant checks.

The retained upstream Home and personalization files are byte-exact provenance snapshots. The focused installable project currently executes a candidate-owned action adapter extracted around those entry semantics; full-file upstream ViewModel/UI execution remains a recorded publication gate.
